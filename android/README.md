# 안드로이드 앱

`가나한걸음.apk`는 **Android 8.0 이상**에서 직접 설치할 수 있는 서명된 APK입니다. 새 글자·복습·필순·음성 파일을 앱에 포함하므로 인터넷 연결이나 계정이 필요하지 않습니다.

휴대폰에 APK를 복사해 파일 관리 앱에서 열고 설치합니다. Android에서 요청하면 해당 파일 관리 앱의 ‘알 수 없는 앱 설치’를 허용합니다. 기존 웹 앱의 기록을 이어 쓰려면 웹 풀이 모드에서 기록을 내보내고, APK의 풀이 모드에서 그 JSON 파일을 가져옵니다. 웹과 APK의 저장소는 별개입니다.

학습 기록과 오늘의 수업은 앱에 자동 저장됩니다. **1.1.0부터** 안드로이드 자동 백업(Google 백업·기기 간 이동)에 학습 기록이 포함되어, 휴대폰을 바꾸거나 다시 설치해도 기록이 돌아올 수 있습니다. 다만 백업 설정과 시점은 기기마다 다르므로, 기록 파일 내보내기를 함께 권합니다. 오랫동안 내보내지 않으면 앱이 알려 줍니다.

## 1.1.0에서 바뀐 점

- Android 8 기본 WebView에서 필순·따라 쓰기 칸이 보이지 않던 문제를 고쳤습니다 (CSS `min()`·`inset` 제거, `verify.js`가 다시 쓰지 않도록 검사).
- 기기의 다크 모드를 따르고, 상태 표시줄·내비게이션 줄 색도 화면 테마에 맞춥니다.
- 뒤로 가기가 한 단계씩 돌아갑니다. 연습 문제를 푸는 중이면 그만둘지 묻고, 오늘의 학습 첫 화면에서만 앱을 닫습니다.
- 학습 기록을 자동 백업에 넣고, 오래 내보내지 않으면 알려 줍니다. 지난 수업 기록은 60일까지만 보관합니다.
- 다른 앱을 잠깐 보고 돌아와도 보던 학습 카드가 닫히지 않습니다.
- 기록 가져오기에서 ‘알 수 없는 형식’으로 보이는 .json 파일도 고를 수 있습니다.
- 런처 모양에 맞춰 잘리는 적응형 아이콘과 Android 13 테마 아이콘을 지원합니다.
- 웹 풀이 모드의 보기 난이도·시간 제한·오늘 복습·하루 목표가 앱에도 들어갔습니다.

## 오늘의 학습

- 기본 수업: **새 글자 5개 → 확인 문제 5개 → 복습 10문제**, 약 10~15분을 시작점으로 사용합니다.
- 하루 새 글자는 3·5·10개, 복습은 5·10·15문제로 조절합니다. 시작한 수업의 양은 유지하고, 변경은 다음 날 수업부터 적용합니다. 아직 시작하지 않은 수업은 바로 변경됩니다.
- 첫날에는 기존 기록이 없으므로 새 글자를 반복해 복습합니다. 이후에는 복습일이 지난 글자, 최근 틀린 글자, 오래 전에 본 글자를 우선합니다.
- 오늘의 수업은 기기의 현지 날짜와 히라가나·가타카나별로 저장됩니다. 중단했다 다시 열면 남은 단계와 문제만 이어갑니다.
- 오늘의 진행도는 카드 확인·문제 풀이를 완료한 비율이며, 오답도 풀이한 문제로 셉니다. 익힘 비율은 **3번 연속 정답** 기준이라 수업 완료율과 다를 수 있습니다.
- 히라가나는 104개, 가타카나는 확장음 포함 120개를 대상으로 ‘만난 글자’와 ‘익힌 글자’를 각각 표시합니다.
- 확인·복습은 읽는 법, 듣고 문자 고르기, 단어 빈칸 채우기를 섞어서 냅니다. 오늘의 수업에는 시간 제한을 적용하지 않습니다.

## 다시 빌드

필요: Node.js, JDK 17 이상, Android SDK API 36 / Build Tools 35.0.0. Gradle 8.14.3 wrapper와 AGP 8.13.0을 사용합니다.

```powershell
npm ci
npm test
./android/build-apk.ps1
```

JDK나 SDK 위치가 다르면 `build-apk.ps1 -JavaHome '경로' -SdkPath '경로'`로 지정합니다. APK는 이 프로젝트 폴더의 상위 폴더에 만들어집니다.

빌드할 때 웹 소스를 자동 복사하고, Android 8의 WebView가 읽을 수 있도록 자바스크립트를 변환합니다. 기본 글꼴을 사용하고, 음성을 포함하며, 외부 네트워크 권한을 요청하지 않습니다. Android에서는 `WebViewAssetLoader`로 앱 내부 콘텐츠만 불러옵니다. 기록 가져오기·내보내기는 시스템 파일 선택 창을 사용합니다.

처음 빌드하면 `android/.signing`에 개인 앱용 서명 키가 만들어집니다. **이 폴더를 별도로 보관해야 이후 버전을 같은 앱으로 업데이트할 수 있습니다.** 서명 키와 암호는 Git에 포함하지 않습니다. 다음 버전에서는 `app/build.gradle`의 `versionCode`와 `versionName`을 올려 빌드합니다.

## 검증

- `npm test`: 가나·음성·보기·간격 복습 및 하루 수업 계획, 단계별 진행도, 이어 풀기와 백업 데이터 검사.
- Android instrumentation: 별도 `com.kana.hangeoreum.qa` 앱을 사용해 실기기 WebView에서 수업과 오프라인 음성, 필순 칸 크기, 뒤로 가기, 테마 연동을 확인합니다. 사용자용 앱의 기록에는 접근하지 않습니다. `setup-qa.py`로 만든 Android 8 에뮬레이터(WebView 69)에서 통과를 확인했습니다.

```powershell
cd android
./gradlew.bat assembleDebug assembleDebugAndroidTest
adb install -r app/build/outputs/apk/debug/app-debug.apk
adb install -r app/build/outputs/apk/androidTest/debug/app-debug-androidTest.apk
adb shell am instrument -w com.kana.hangeoreum.qa.test/com.kana.hangeoreum.KanaSmokeTest
```
